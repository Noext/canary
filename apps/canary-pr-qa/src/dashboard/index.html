Comment ça fonctionne

Une PR, des preuves concrètes.

  1. Canary lit les changements
    Il déduit les scénarios à vérifier.
  2. Chromium joue les scénarios
    Sur la version exacte de votre PR.
  3. Vous obtenez un verdict
    Assertions, vidéo et rapport GitHub.
La preview doit représenter le commit de la PR. La vérification vous indique ce qui manque avant de lancer l'IA.
